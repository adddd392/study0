* **模型架构演进**：

  * 经典架构：ResNet（残差连接原理与退化问题推导）。

    * 1.退化问题
        &emsp;退化问题"是在同样训练配置下深层网络训练误差不如浅层网络的现象。成因是由深度加深引起的层间连乘增加导致的输入-输出雅可比条件数κ增大引起的强各向异性和非线性层的增加引起的恒等变换难以学习。在二者共同作用下优化轨迹在高损失平台长时间滞留，训练误差下降缓慢。
    * 2.残差连接原理
        &emsp;y=f(x)改为y=f(x)+x;
            &emsp;使得恒等映射容易学习
            &emsp;①f=0情况下有y=x的默认解
            &emsp;②梯度反向传播过程中提供越过f直接向x传播的无衰减支路
  * 轻量化架构：MobileNetV3（深度分离卷积 + NAS搜索 + SE模块）、ShuffleNetV2（硬件友好度设计原则）。
    * MobileNetV3
        * 1.深度可分离卷积
            深度卷积+逐点卷积。$与标准卷积计算量比=\frac{K_H*K_W+C_{out}}{C_{out}*K_H*K_W} $  卷积核，输出通道越大，相对标准卷积越压缩
            实际延迟不一定下降
            * 相比标准卷积，深度可分离卷积算术强度(flops/bytes)降低，在同样字节搬运量下，标准卷积能进行更多计算。
            * DW单任务量过小，并行度低
        * 2.SE模块
            att=MLP(GAP(h,w)),将att按通道乘回特征层
            插入在通道数多，分辨率低的特征层
        * 3.NAS搜索
            * 搜索维度
                * 卷积核大小
                * 主干网络输出通道数与MLP隐藏层通道数比
                * 主干网络输出通道数
                * SE放置位置
            * 目标函数
                platform-aware=$ACC*[\frac{LAT}{T}]^w$
    * ShuffleNetV2（硬件友好度设计原则）
        * 目标：提升算术强度
            * G1 计算量一定输入输出矩阵通道相同时内存访问代价最小
                basic block将输入通道分为两组，一组直接输出，另一组进过深度可分离卷积输出，之后洗混通道，全程保持通道总数不变
            * G2 组卷积分组数增加，内存访问增加
                相对与v1，v2去除了分组卷积。通道间交换信息由混洗承担，这个操作的 FLOPs 是O（0），mac是O(hwc)  卷积分组数为1，mac降低
            * G3 网络越碎片化，并行度越低
                碎片化=一个block内独立算子过多+kernel过小
            * G4 逐元素操作在延迟中不可忽略，但是flops占比很低
                逐元素操作包括激活函数，归一化层，张量间对齐/广播，逐通道算子（DW，池化）。特点是flops小，但是需要读取整个张量，复用率低。

  * 现代化与前沿架构：ConvNeXt / ConvNeXt-V2（借鉴 Transformer 的现代化 CNN）、Vision Transformer (ViT)、Swin Transformer（分层滑动窗口注意力）。
    * Vision Transformer (ViT)
        * patch embedding
            进行核大小为P，步幅为S的卷积，输出通道为D。
            将H，W展平，输出为(HW,D)
        * self-attention
            复杂度O($[\frac{HW}{P^2}]^2D$)
            将通道D经过线性投影得到3D的输出通道，按通道分组得到Q，K，V(各D维)，多头再且成h分
            att=softmax($\frac{QK^T}{\sqrt{D/h}}$)*V
            多头将att拼接回D维
        * ViT对比CNN
            * 归纳偏置
                ||局部性|权重共享|层次化|
                | ------- | ------- | ------- | ------- |
                |CNN|输出依赖于邻域|同一卷积核可以处理图像的所有位置|逐层降采样|
                |ViT|保留每个patch的局部性，patch间可以交互|使用绝对位置编码，att使用全局softmax|
                
                ViT的$\frac{可学习偏置}{内置偏置}$更大,需要更大数据集
